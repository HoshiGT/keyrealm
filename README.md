# Keyrealm

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey.svg)
![Python](https://img.shields.io/badge/python-3.11%2B-blue.svg)

**ALL-IN-ONE 的本地凭据管理与验证平台。** 把散落在各处的 API Key、云厂商 AK/SK、机器人 Token、
邮箱授权码、登录态集中加密保管，并**主动验证它们是否仍然可用**——不用等到某次调用失败才发现
某把 Key 早就被停用或欠费了。

数据**只存在你自己机器的程序目录里**，不联网同步、不上传云端；需要联网的只有「验证」这一步，
且每个服务是否走代理、走哪个代理都可以逐条指定。

## 功能

### 加密存储

- **AES-256-GCM 字段级加密**，密钥由主密码经 PBKDF2-HMAC-SHA256 派生，仅存内存。
- 敏感字段与非敏感字段分列存放：列表展示不必解密，同时保证密钥类字段全程不落明文。
- 主密码**没有任何找回途径**（无后门、无恢复码）——这是设计，见[安全说明](#安全说明)。

### 主动验证

- **单条 / 批量 / 定时**三种方式。批量验证并发数与请求超时可在对话框里就地调整。
- 定时计划的验证范围可选**全部 / 指定分组 / 指定类型 / 指定凭据**。
- 校验结果不只是「有效 / 无效」：能拿到余额的显示余额，套餐类显示使用率，云厂商显示账号信息；
  无效字段自动隐藏，中转站的「不限额度」哨兵值不会被渲染成假余额。
- 对**拿不到余额**的服务（厂商没有余额接口），可在该凭据上单独开启**欠费探测**：额外发一次
  最小对话请求，把「Key 有效」升级为「实测可用 / 实测欠费」。默认关闭。
- 有写副作用或无法自动化的类型（如 DuckDNS、Telegram api_id/hash、短信网关）标记为
  **不参与批量验证**，只允许手动逐条验证，避免把人工判定的结果刷掉。

### 插件化

- 一个服务一个插件，共 **63 个插件、10 个类别**（见[支持的服务](#支持的服务)）。
- 插件放在程序目录的 `plugins/` 下，**放入即加载、删除即卸载**，无需安装器；
  临时停用无需删目录，在界面里禁用即可（状态记在 `plugins/.state.json`）。
- 禁用**不动磁盘目录**：名下凭据照常显示、可编辑、可导出，只是「操作」「验证」置灰、
  批量验证自动跳过。

### 凭据操作

部分插件在验证之外还提供操作，随凭据行出现「操作」按钮：

- **对话**：对 LLM 凭据直接发一次简单对话（流式返回）。
- **表单**：带写副作用的操作（如修改 DNS 解析记录、刷新令牌），提交前二次确认。
- **列表**：可下钻的查询，如「云主机实例」「对象存储桶 → 对象浏览」「域名列表 → 解析记录」。

没权限的操作会自动隐藏（插件探测该凭据的真实权限），一个都没有时给出说明。

### 代理

- 可维护**多个代理**，设一个全局默认；**每条凭据**可三选一：跟随上层设置 / 指定某个代理 / 直连。
  解析优先级为 `本条凭据 > 该插件预设 > 所属类别预设 > 全局默认`。
- 代理支持 `http` / `https` / `socks4` / `socks5` / `socks5h`。
- 任一代理可一键**对照测试**：同一批探测分别走直连与代理，比对出口 IP 归属与国内外站点可达性，
  直接给出「代理是否真的生效」的结论。
- 邮箱（SMTP / IMAP）走裸 TCP，吃不了 HTTP 代理，会自动改用 SOCKS / HTTP CONNECT 隧道穿出去。

### 备份与恢复

- 导出为单个 JSON 文件：**加密导出**（保留密文）或**明文导出**（可跨主密码导入）。
- 可选「**全部**（凭据 + 分组 + 代理 + 预设 + **定时计划 + 设置 + 保险库 KDF + MCP + 插件启停**）」
  或「仅选中的凭据」。整库档自带**盐（salt）**，所以这份文件是**自包含**的——**原库损坏或丢失也能还原**。
- 导入是**填充式**的：以当前库为蓝本，把备份条目填进去，**不删也不覆盖**既有数据。
  插件不存在或被禁用、含当前插件不认识的字段、缺少必填字段的条目会**整条判失败、不写库**，并逐条列出原因；
  每次导入在 `data/logs/` 下留一份完整导入日志与（有失败时）一份失败日志，结果弹窗里可一键打开便于人工补录。
- **换保险库也能还原**：在另一台机器 / 新装的 Keyrealm 上导入整库备份时，会**再问一次它当时的主密码**——
  用它 + 文档里的盐派生源密钥解开密文，再以**当前库的密钥重新加密**写回（当前库自己的盐/校验值不受影响）。

### 其它

- **凭据简易操作、分组管理、6 套界面主题**（3 浅 3 深）、侧边栏与凭据目录树顺序均可拖拽调整。
- **后台任务**：下载 / 打包这类长操作登记为任务，可看进度、可取消，关掉弹窗照常跑；
  任务记录持久化到 `data/tasks.json`，重启后历史仍在（上次没跑完的标为「已中断」）。
- **独立日志页**：级别可调、支持关键词搜索（含 traceback 的整条记录匹配）。
- **单实例**：重复启动不会开出第二个窗口，而是把已运行的拉到前台。
- **开机自启动**（默认关闭）。
- **跨平台**：Windows 优先，兼容 macOS / Linux。

## 下载与安装

### Windows / macOS

从 [Releases](../../releases) 下载对应平台的压缩包
（`Keyrealm-<版本>-windows-x64.zip` / `macos-arm64.zip`），解压后直接运行，免安装。

- **Windows**：运行 `Keyrealm.exe`。需要 **WebView2 Runtime**（Windows 10/11 通常已内置；
  若启动时报缺 WebView2，从微软官网装一次即可）。
- **macOS**：运行包内的 `Keyrealm`。**未签名**——首次打开会被 Gatekeeper 拦，右键→「打开」，
  或终端执行 `xattr -dr com.apple.quarantine Keyrealm` 放行。

首次运行会在程序同级目录创建 `data/`（数据库、日志、界面偏好都在这里）。

### Linux

暂无预编译包，需从源码运行，见 [CONTRIBUTING.md](CONTRIBUTING.md) 的开发环境一节。

## 快速上手

1. **设置主密码。** 首次启动要求设置主密码——它用于派生加密密钥。
   **忘记即无法恢复**，请自行妥善保存。
2. **添加凭据。** 在左侧「凭据目录」选一个服务 → 点「添加凭据」→ 按表单填写。
   表单字段由插件声明（如 API Key、Base URL、备注），敏感字段保存前即加密。
   也可以先给某个**类别或插件**设好默认值（Base URL、备注、走哪个代理），新建时自动带出。
3. **验证。** 保存后默认自动验证一次；之后可随时点行内「验证」，或用工具栏的「批量验证」
   勾选多条一起验，或在「任务」页配置定时验证计划。
4. **看结果。** 列表里的「状态」列给出结论，「附加信息」列给出余额 / 使用率 / 账号信息；
   有些凭据行还会出现「操作」按钮，可做验证之外的查询与操作。

## 接入 AI Agent（MCP）

Keyrealm 内置一个 **MCP Server**，Agent 可以直接查询、创建、验证凭据，不必把密钥复制到
聊天上下文里。

1. 在「设置 → MCP 服务」页**手动启动**服务（默认监听 `127.0.0.1:8765`，仅本机）。
   端口被占用时会**直接报错而不自动换端口**——端口是你显式配置的，悄悄换掉更让人困惑。
2. 页面提供现成的客户端配置 JSON 与访问 Token（Bearer）。把配置粘进 Claude Desktop / Cursor /
   Claude Code 等客户端即可。
3. **工具权限默认关闭**，需要在同一页逐个开启。共 20 个工具：读类默认开，写与高危类默认关
   （开启前二次确认）。高危及写操作包括获取明文密钥、创建 / 修改 / 删除凭据、导出 / 导入备份、
   以及**验证代理的管理**——代理决定「凭据的验证流量发到哪」，被改动等于把出口交给别人指定的地址。

> Token 明文**只在轮换时展示一次**，数据库只存哈希与前缀。鉴权失败返回 401；
> 工具权限不足则返回一份**可读的拒绝说明**（含原因与「去哪里开启」），而不是一句
> `Error executing tool`。

完整接口规范见 [MCP 接口规范](docs/MCP_API.md)。

## 安全说明

| 项目 | 做法 |
|---|---|
| 加密算法 | AES-256-GCM（字段级，带认证） |
| 密钥派生 | PBKDF2-HMAC-SHA256，10 万次迭代，随机 16 字节 salt |
| 密钥存放 | 派生密钥**只存在内存**，锁定时立即清除 |
| 数据位置 | 程序目录下的 `data/`，不联网同步、不上传任何第三方 |
| 网络行为 | 仅「验证 / 操作」时按你的配置发起请求；MCP Server **默认不启动**、仅监听本机 |
| 输出净化 | 插件的返回文本与日志会过滤掉回显的敏感字段值 |
| 空闲锁定 | 可选：一段时间无操作后自动清除内存密钥 |

**主密码无法找回。** 加密密钥由主密码派生，没有任何后门或恢复码——丢了主密码就丢了解密能力。
建议定期用「备份」页导出（**记得用同一个主密码**，或选择明文导出自担风险）。

## 常见问题

**Q：忘记主密码了怎么办？**
无法恢复。只能删掉 `data/` 目录重新开始（已加密的数据无法解密）。

**Q：数据存在哪里？怎么整机迁移？**
程序的 `data/` 目录：`credentials.db`（凭据库）、`logs/`（日志）、`tasks.json`（任务记录）、
`webview/`（界面偏好）。整机迁移直接拷 `data/` 即可（主密码随之带走）。
也可以只用「备份」页导出 JSON 迁移，粒度更细。

**Q：升级会不会丢数据 / 重置我的插件启用状态？**
不会。升级只替换程序与 `plugins/`，`data/` 原样保留，`plugins/.state.json`（启用 / 禁用状态）
也不会被覆盖。

**Q：怎么更新到新版本？**
两种渠道，在「设置 → 更新」里选：
- **正式版**：从 GitHub Release **下载对应平台的预编译包替换当前程序**（不编译），更新前会把可执行文件、
  `plugins/`、`data/` 备份到 `data/backup/`（只留最近一份），数据库结构有变动会**逐级**自动迁移。
- **测试版**：跟 `main` 最新提交**从源码重新构建**（本机没有源码会先拉一份到程序目录）。

两种更新前都会自动备份、完成后**自动重启**。默认**开启「自动检测更新」**——每次程序启动后会自动查一次，
发现新版本弹通知提醒；也可以随时在「设置 → 更新」手动检查。点「立即更新」后：**先在程序内准备**
（备份 + 下载/拉源码 + 构建，有进度条、可取消），准备完成才自动关闭程序完成替换/迁移，再重启；
重启后「上次更新」有逐阶段报告。
也可以手动从 [Releases](../../releases) 下载压缩包。
详见 [程序内更新](docs/UPDATE.md)。

**Q：某个服务验证失败或有超时，是不是我的 Key 坏了？**
先看是不是网络问题。部分厂商（Telegram、Discord、Hugging Face 等）在国内需要代理才能访问，
请在「设置 → 网络与代理」里配好代理，再对该凭据指定出口。SMTP 若服务器只支持 TLS 1.0/1.1，
需要在凭据里勾选「允许旧版 TLS」（默认关，因为这会降低信道强度）。

**Q：用 SOCKS5 代理提示缺少依赖？**
打包版**已内置** socks 支持，正常不会遇到。只有从源码运行时才需要装一次：
`pip install "httpx[socks]"`。

**Q：MCP 服务启动失败？**
多半是端口被占用。到「设置 → MCP 服务」改一个端口再启动（应用不会自动换端口）。

**Q：日志在哪里？**
`data/logs/keyrealm.log`（1 MB × 5 轮转），也可以在「日志」页里直接查看与搜索。

**Q：验证会不会产生费用或副作用？**
校验一律使用**只读**接口，不会修改你在厂商侧的任何配置。唯一的例外是插件显式提供、
由你**手动点击**的操作（如修改 DNS 记录、刷新登录态令牌）；另有「欠费探测」会额外发一次
极小的对话请求（默认关闭，开启时会消耗极少量额度）。
